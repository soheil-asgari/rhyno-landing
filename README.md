# Rhyno AI - Landing Page (Standalone)

این پروژه شامل صفحه اصلی و صفحه تماس با ما سایت **Rhyno AI** است که به صورت کاملاً ایستا (Static) و بدون نیاز به بک‌اند، قابل اجرا می‌باشد.

## نحوه اجرا

برای اجرای سایت، کافیست یکی از روش‌های زیر را انجام دهید:

### روش ۱: باز کردن مستقیم فایل‌ها
فایل `index.html` را با مرورگر باز کنید.

### روش ۲: استفاده از Live Server (توصیه می‌شود)
اگر VS Code دارید، افزونه **Live Server** را نصب کنید و روی `index.html` کلیک راست کرده و **Open with Live Server** را انتخاب کنید.

### روش ۳: اجرا با Python
```bash
python -m http.server 8000
```
سپس در مرورگر به آدرس http://localhost:8000 بروید.

### روش ۴: اجرا با Node.js
```bash
npx serve .
```

## ساختار فایل‌ها

```
rhyno-landing/
├── index.html          # صفحه اصلی سایت (لندینگ)
├── contact.html        # صفحه تماس با ما
├── css/
│   └── style.css       # استایل‌های کامل (همراه با پشتیبانی از تم تاریک/روشن)
├── js/
│   └── main.js         # اسکریپت‌ها (تغییر تم، منوی موبایل، انیمیشن‌ها، فرم تماس)
└── assets/
    ├── rhyno-logo.png  # لوگوی سایت
    └── fonts/
        └── Vazirmatn-VariableFont_wght.ttf  # فونت وزیرمتن
```

## ویژگی‌ها

- **بدون نیاز به بک‌اند** – به صورت کاملاً ایستا اجرا می‌شود
- **تم تاریک/روشن** – با قابلیت ذخیره‌سازی در localStorage
- **طراحی واکنش‌گرا** – مناسب برای موبایل، تبلت و دسکتاپ
- **انیمیشن‌های CSS** – بدون نیاز به کتابخانه خارجی
- **فرم تماس** – با استفاده از **Web3Forms** (رایگان) برای ارسال پیام

## تنظیم فرم تماس

برای کار کردن فرم تماس، باید یک اکانت رایگان در [Web3Forms](https://web3forms.com/) بسازید و `access_key` دریافتی را در فایل `js/main.js` جایگزین کنید:

```js
access_key: "YOUR_WEB3FORMS_ACCESS_KEY",
```

## تصاویر و منابع

تمامی مسیرهای منابع به صورت относительные (نسبی) تنظیم شده‌اند، بنابراین پروژه در هر مسیری قابل اجرا است.
